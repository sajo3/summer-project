A Practical Guide

Learn PHP

PHP runs over three-quarters of the web, from WordPress to Wikipedia. This guide takes you from zero to writing real, useful scripts—no prior programming experience assumed.

Chapter 1

What is PHP?

PHP is a server-side scripting language. That means PHP code runs on the web server before the browser ever sees a page. When someone visits a URL that points to a PHP file, the server executes the code, and the result—usually HTML—is sent to the visitor.

PHP powers content management systems (WordPress, Drupal), e-commerce platforms (Magento, WooCommerce), and frameworks (Laravel, Symfony). It’s also the engine behind a large chunk of the modern web.

You write PHP inside files that end in .php. Code goes between <?php and ?> tags:

<?php
echo "Hello, world!";
No closing tag needed If a file contains only PHP code, omit the closing ?> tag. It prevents accidental trailing whitespace that can break HTTP headers.
Chapter 2

Getting set up

PHP ships with a built-in development server. You don’t need Apache or Nginx to start learning.

Check if PHP is installed

php --version

If you see a version number (8.0 or later is ideal), you’re set. If not, install PHP from php.net, your package manager (brew install php on macOS, apt install php on Ubuntu), or a bundled tool like Laragon (Windows) or Herd (macOS/Windows).

Start the built-in server

Create a project folder and start PHP’s built-in server from inside it: 

mkdir my-first-php && cd my-first-php
php -S localhost:8080

Now open http://localhost:8080 in your browser. The server will look for an index.php file to serve. Let’s create one.

Stopping the server Press Ctrl + C in your terminal to shut it down when you’re done.
Chapter 3

Your first script

Inside your project folder, create a file called index.php with these contents: 

<?php
$greeting = "Hello from PHP!";
$year = date("Y");
echo "<h1>$greeting</h1>";
echo "<p>The year is $year.</p>";

Refresh your browser. You should see a heading and the current year.

Let’s break down what happened:

  • $greeting and $year are variables—named containers that hold values.
  • date("Y") is a built-in function that returns the current four-digit year.
  • echo sends text to the browser.
  • Variables inside double-quoted strings are expanded to their values.
Chapter 4

Variables and types

In PHP, every variable starts with a dollar sign $. You don’t declare a type upfront—PHP figures it out from the value you assign. 

$name      = "Saja";           // string
$age       = 29;               // integer
$price     = 19.99;            // float
$published = true;             // boolean
$tags      = ["php", "web"];   // array

var_dump() is your debugging friend. It prints the type and value of any variable: 

var_dump($name);    // string(4) "Saja"
var_dump($age);     // int(29)
var_dump($price);   // float(19.99)
var_dump($tags);    // array(2) { [0]=> string(3) "php" [1]=> string(3) "web" }

String concatenation

Join strings together with a dot .:

$first = "Hello";
$last  = "World";
echo $first . ", " . $last . "!";   // Hello, World!

Common string functions

Chapter 5

Making decisions

Programs need to branch based on conditions. PHP gives you if, else, and elseif. 

$hour = date("H");  // 24-hour format

if ($hour < 12) {
    echo "Good morning!";
} elseif ($hour < 18) {
    echo "Good afternoon!";
} else {
    echo "Good evening!";
}

Comparison operators

Always use strict comparison == will try to coerce types — 0 == false is true, which can hide bugs. Prefer === and !== unless you specifically need loose comparison.
Chapter 6

Loops

Loops let you repeat a block of code. PHP has four main loop types.

while

Repeats as long as a condition is true:

$count = 1;
while ($count <= 5) {
    echo "Count: $count<br>";
    $count++;
}

for

Packs the initializer, condition, and increment into one line:

for ($i = 0; $i < 5; $i++) {
    echo "Iteration $i<br>";
}

foreach

The best way to iterate over arrays:

$fruits = ["apple", "banana", "cherry"];

foreach ($fruits as $fruit) {
    echo "I like $fruit<br>";
}

// With keys:
foreach ($fruits as $index => $fruit) {
    echo "$index: $fruit<br>";
}
Use foreach for arrays foreach is cleaner and less error-prone than for when you just need to go through every item. It also works on associative arrays (key-value pairs).
Chapter 7

Functions

A function is a named block of reusable code. You define it once and call it as many times as you need.

Defining and calling

function greet(string $name, string $timeOfDay = "morning"): string
{
    return "Good $timeOfDay, $name!";
}

echo greet("Saja");               // Good morning, Saja!
echo greet("Ahmed", "evening");   // Good evening, Ahmed!

What’s happening here:

  • greet is the function name.
  • string $name is a typed parameter — the function expects a string.
  • $timeOfDay = "morning" is a default parameter — optional, falls back to "morning".
  • : string after the parentheses is the return type — the function promises to return a string.

Scope

Variables defined inside a function are local to that function. Variables defined outside are not available inside unless you pass them as arguments or use the global keyword (which you should generally avoid).

$outside = "visible out here";

function demo(): void
{
    $inside = "only visible in here";
    // $outside is NOT accessible here
}
Chapter 8

Handling forms

PHP makes form handling straightforward. Data from a form arrives in superglobal arrays — $_GET for query strings and $_POST for form submissions.

A simple form

Create contact.php:

<?php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $name = htmlspecialchars($_POST["name"] ?? "");
    $message = htmlspecialchars($_POST["message"] ?? "");

    if ($name !== "" && $message !== "") {
        echo "<p>Thanks, $name! Your message was received.</p>";
    } else {
        echo "<p>Please fill in both fields.</p>";
    }
}
?>

<form method="post" action="contact.php">
    <label for="name">Your name</label>
    <input type="text" name="name" id="name">

    <label for="message">Message</label>
    <textarea name="message" id="message"></textarea>

    <button type="submit">Send</button>
</form>

Key points:

  • $_SERVER["REQUEST_METHOD"] tells you whether the page was loaded normally (GET) or submitted (POST).
  • $_POST["name"] ?? "" uses the null coalescing operator ?? — if the key doesn’t exist, it defaults to an empty string.
  • htmlspecialchars() escapes HTML characters, preventing XSS attacks where a user injects <script> tags.
Never trust user input Always escape output with htmlspecialchars() when printing user-submitted data back to the page. When working with databases later, use prepared statements to prevent SQL injection.
Chapter 9

What’s next

You’ve covered the fundamentals: variables, conditionals, loops, functions, and form handling. These building blocks appear in every PHP application. Here’s where to go from here:

Databases

Most applications store data in a database. PHP’s PDO extension gives you a consistent interface for MySQL, PostgreSQL, and SQLite. Start with SQLite — it requires no separate server.

Frameworks

Once you’re comfortable with raw PHP, a framework like Laravel or Symfony gives you routing, templating, authentication, and database tools out of the box.

Keep building

The fastest way to learn is to build something you actually want. A to-do list, a simple blog, a guestbook — pick a small project and finish it. The PHP manual at php.net is excellent and worth bookmarking.
